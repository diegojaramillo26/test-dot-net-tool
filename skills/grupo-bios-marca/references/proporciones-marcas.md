# Proporciones entre Marcas — Reglas Detalladas

La unidad base **"x"** = altura de la palabra "Grupo" en el logo de Grupo Bios.

---

## CASO 1: Logo Grupo Bios + Marca de Producto

Aplica cuando el logo corporativo de Grupo Bios aparece junto a una marca de producto
(Contegral, Finca, ABS, Friko, Ringo, Mirringo, Filpo, Nutriss, Vivance, PTC, etc.)
separados por una línea vertical.

### Distancia entre logos
- **2x** a la izquierda del logo Grupo Bios (desde el borde del área de seguridad)
- **2x** entre el logo Grupo Bios y la línea separadora
- **2x** entre la línea separadora y el logo de producto
- **2x** a la derecha del logo de producto

### Altura del logo de producto (jerarquía visual)

**Regla del umbral de la mitad:**
Mide el ancho del logo de producto y compáralo con el ancho total del logo Grupo Bios.

```
[    GRUPO BIOS    ]
         ↕ mitad
```

| Condición | Margen arriba | Margen abajo |
|---|---|---|
| Ancho producto < mitad del ancho Grupo Bios | ½x | ½x |
| Ancho producto ≥ mitad del ancho Grupo Bios | x | x |

### Ejemplos de aplicación
- **Contegral** (logo pequeño circular) → ancho < mitad → margen ½x arriba y ½x abajo
- **Mirringo** (logo ancho tipográfico) → ancho ≥ mitad → margen x arriba y x abajo
- **Friko** (logo circular mediano) → evaluar según tamaño real
- **Ringo** → tipografía ancha → probablemente x arriba y x abajo
- **Finca** → logo circular pequeño → ½x
- **ABS** → logo cuadrado compacto → evaluar
- **Filpo** → tipografía con personaje → evaluar ancho total

---

## CASO 2: Logo con Marca de Negocio + Marca de Producto

Aplica cuando se usa el logo de Grupo Bios con la denominación de negocio
(Nutrición Animal / Consumo Masivo / Genética) junto a una marca de producto.

### Distancia entre logos
Igual que el Caso 1: **2x** en todos los intervalos.

### Altura del logo de producto (jerarquía visual)

La diferencia respecto al Caso 1 es que los márgenes son mayores porque el bloque
Grupo Bios + marca de negocio es visualmente más alto:

| Condición | Margen arriba | Margen abajo |
|---|---|---|
| Ancho producto < mitad del ancho Grupo Bios | x | x |
| Ancho producto ≥ mitad del ancho Grupo Bios | 2x | 2x |

### Ejemplos de aplicación (Caso 2)
```
[GRUPO BIOS / NUTRICIÓN ANIMAL]  |  [CONTEGRAL]   → x arriba y x abajo
[GRUPO BIOS / CONSUMO MASIVO]    |  [MIRRINGO]    → 2x arriba y 2x abajo
[GRUPO BIOS / CONSUMO MASIVO]    |  [FRIKO]       → evaluar
[GRUPO BIOS / GENÉTICA]          |  [ABS]         → x arriba y x abajo
```

---

## CASO 3: Marcas de Producto entre ellas (sin logo Grupo Bios)

Cuando el logo del Grupo Bios no aparece en el material, las marcas de producto
se organizan entre sí siguiendo las mismas reglas del Caso 1 para mantener coherencia.

### Distancia entre marcas de producto
- **2x** entre cada logo y la línea separadora.

### Altura relativa entre logos de producto
- Se toma el logo más grande del conjunto como referencia de altura.
- Logos más pequeños: margen ½x arriba y abajo.
- Logos de tamaño similar o mayor a la mitad del más grande: margen x arriba y abajo.

### Combinaciones frecuentes documentadas
```
Grupo 1 (nutrición animal / genética):
CONTEGRAL | FINCA | ABS | PTC
→ Todos son logos relativamente pequeños: margen ½x

Grupo 2 (consumo masivo):
FILPO | RINGO | MIRRINGO | NUTRISS | VIVANCE
→ Logos más anchos: margen x para la mayoría
→ FILPO (pequeño circular): ½x
→ NUTRISS (mediano): ½x
```

## Logo con Marca de Negocio — Construcción del bloque

El bloque de "logo con marca de negocio" se construye así:

```
┌─────────────────────────┐
│  [ícono] GRUPO           │
│          Bios            │
│  N U T R I C I Ó N      │
│  A N I M A L            │
└─────────────────────────┘
```

- La denominación de negocio va en **caja alta con tracking amplio** debajo del logo.
- La distancia entre el logo y la denominación equivale al **ancho de la letra "i"** del logo.
- El bloque completo tiene un tamaño mínimo de **25 mm de ancho**.

### Denominaciones de negocio disponibles
- `NUTRICIÓN ANIMAL`
- `CONSUMO MASIVO`
- `GENÉTICA`

---

## Línea separadora entre logos

- La línea es **vertical**, del mismo color que el logo (azul petróleo en versión positiva,
  blanco en versión negativa).
- Su altura se alinea con la altura total del logo o bloque de marca de negocio.
- Grosor: proporcional, aproximadamente 1 pt a tamaño estándar.

## Resumen visual de márgenes

```
CASO 1 — Logo simple + producto pequeño:
  2x | [GRUPO BIOS] | 2x | línea | 2x | [logo] | 2x
                              ↕½x producto ↕½x

CASO 1 — Logo simple + producto grande:
  2x | [GRUPO BIOS] | 2x | línea | 2x | [logo grande] | 2x
                               ↕x producto ↕x

CASO 2 — Marca negocio + producto pequeño:
  2x | [GRUPO BIOS / NEG.] | 2x | línea | 2x | [logo] | 2x
                                    ↕x producto ↕x

CASO 2 — Marca negocio + producto grande:
  2x | [GRUPO BIOS / NEG.] | 2x | línea | 2x | [logo grande] | 2x
                                    ↕2x producto ↕2x
```
