# Paleta de Colores Corporativos — Grupo Bios

Todos los valores son exactos y deben usarse sin variación en materiales de la marca.

---

## COLORES PRINCIPALES

### 1. Azul Petróleo
El color dominante de la marca. Usado en la tipografía del logo y como fondo principal.

| Sistema | Valor |
|---|---|
| **Pantone** | 315 C |
| **CMYK** | C: 100 / M: 5 / Y: 22 / K: 40 |
| **RGB** | R: 0 / G: 101 / B: 127 |
| **HEX** | `#00657F` |

**Usos principales:**
- Tipografía "Grupo Bios" en el logo
- Fondos de comunicaciones institucionales
- Textos sobre fondos claros
- Líneas separadoras entre logos (versión positiva)

---

### 2. Verde
El color secundario principal. Usado en el ícono del logo y como acento de energía y naturaleza.

| Sistema | Valor |
|---|---|
| **Pantone** | 3507 C |
| **CMYK** | C: 32 / M: 0 / Y: 92 / K: 0 |
| **RGB** | R: 170 / G: 207 / B: 0 |
| **HEX** | `#AACF00` |

**Usos principales:**
- Ícono del logo (hojas y arco)
- Acentos y elementos destacados

## Combinaciones de color correctas

| Fondo | Texto / Logo | ¿Correcto? |
|---|---|---|
| Azul Petróleo (#00657F) | Logo bicromático / texto blanco | ✅ |
| Azul Petróleo (#00657F) | Logo verde | ✅ |
| Verde (#AACF00) | Logo azul petróleo / texto azul petróleo oscuro | ✅ |
| Azul Petróleo Oscuro (#004853) | Logo bicromático | ✅ |
| Naranja (#FFAC00) | Logo monocromático blanco | ✅ |
| Naranja (#FFAC00) | Logo bicromático | ❌ (bajo contraste) |
| Beige (#ECEBE0) | Logo bicromático / texto azul petróleo | ✅ |
| Color no corporativo | Logo monocromático (si contraste suficiente) | ⚠️ Solo si necesario |
| Color no corporativo con bajo contraste | Cualquier logo | ❌ |

---

## Notas de implementación digital

- En pantalla, usar siempre valores **HEX o RGB exactos**.
- No usar aproximaciones (ej: no usar `#006680` en lugar de `#00657F`).
- Para web, los colores son seguros para WCAG AA si se combinan correctamente
  (azul petróleo sobre blanco cumple ratio de contraste).
- El verde (#AACF00) sobre blanco puede tener bajo contraste para texto pequeño;
  reservarlo para ícono del logo y elementos gráficos grandes.
- En impresión offset, siempre especificar los valores Pantone al proveedor.
